## Usage

To run the Flask application:

```bash
# Ensure GEMINI_API_KEY is set as an environment variable
export GEMINI_API_KEY="YOUR_API_KEY"
python -m src.my_chat_app.routes
```
(You might need to adjust the run command depending on how the Flask app is structured to be run from the package)
